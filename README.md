# 📚 Snap & Study

Snap & Study is an AI-powered study assistant that helps students understand questions, notes, diagrams, and textbook pages using Gemini Vision.

## ✨ Features

- 📸 Upload study images
- 🤖 AI-powered explanations using Gemini
- 💬 Ask follow-up questions
- 📖 Learn Mode and ⚡ Exam Mode
- 📝 Generate revision notes
- 📧 Send notes directly to email using Gmail

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- Gmail SMTP
